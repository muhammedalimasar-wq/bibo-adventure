# مغامرة بيبو 🤠🌃🌳

لعبة منصات بثلاثة أشكال: كلاسيك، ونيون، وكاوبوي. تشتغل على الكمبيوتر وعلى الموبايل، ومن غير إنترنت.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | اللعبة كلها |
| `manifest.webmanifest` + `icons/` | يخلّوا اللعبة تتثبّت على الشاشة الرئيسية للموبايل زي التطبيق |
| `sw.js` | يحفظ اللعبة على الموبايل عشان تفتح من غير نت |
| `.github/workflows/build-apk.yml` | GitHub يبني تطبيق أندرويد (APK) لوحده |

## ١) رفع المشروع على GitHub
1. اعمل مستودع (Repository) جديد **Public** باسم `bibo-adventure`.
2. اختار **Add file ← Upload files**، واسحب كل الملفات والفولدرات (`index.html` و`manifest.webmanifest` و`sw.js` و`README.md` وفولدر `icons`).
3. فولدر `.github` مخفي على بعض الأجهزة. لو مارفعش، اختار **Add file ← Create new file**، واكتب الاسم `.github/workflows/build-apk.yml`، والصق محتوى الملف، وبعدين **Commit**.

## ٢) رابط اللعبة (أندرويد + آيفون) — GitHub Pages
1. في المستودع اختار **Settings ← Pages**.
2. في **Source** اختار **Deploy from a branch**، وفي **Branch** اختار `main` و`/(root)`، وبعدين **Save**.
3. بعد دقيقة أو اتنين هيظهر الرابط: `https://اسم-حسابك.github.io/bibo-adventure/`

**تثبيتها على الموبايل:**
- **آيفون:** افتح الرابط من **Safari**، ودوس زرار المشاركة ⬆️، واختار **إضافة إلى الشاشة الرئيسية**.
- **أندرويد:** افتح الرابط من **Chrome**، ودوس ⋮، واختار **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

افتح اللعبة مرة واحدة وانت متوصل بالنت، وبعد كده هتشتغل من غير نت.

## ٣) ملف تطبيق أندرويد (APK) — GitHub Actions
1. بعد ما ترفع الملفات، افتح تبويب **Actions**. التشغيل اسمه **Build Android APK** وبياخد حوالي ٥ دقايق.
   (لو مالقيتهوش بيشتغل، اختاره ودوس **Run workflow**.)
2. لما تظهر ✅ افتح التشغيل، وانزل لـ **Artifacts**، ونزّل `bibo-adventure-apk`. هتلاقي جواه ملف `bibo-adventure.apk`.
3. انقل الملف للموبايل وثبّته. لو طلب منك، فعّل «السماح من هذا المصدر».

## تحديث اللعبة بعدين
ارفع `index.html` الجديد مكان القديم، وغيّر السطر `const VERSION = 'bibo-v1'` في `sw.js` لـ `'bibo-v2'`. كده الموبايلات هتاخد النسخة الجديدة، وGitHub هيبني APK جديد لوحده.
